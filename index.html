komugi

口コミ探偵こむぎ（Instagram / TikTok: cosme_intro）

komugi is a small internal tool used only by the operator of the cosme_intro accounts. It reads the operator's own account statistics (followers, video views, likes, comments, shares) through the official TikTok and Instagram APIs, so the operator can review how each video performed.

komugi は、cosme_intro のアカウントの運営者だけが使う社内用の道具です。公式の API を通して、運営者自身のアカウントの数字（フォロワー数・再生数・いいね・コメント・シェア）を読み、動画ごとの結果を振り返るために使います。

It is not offered to the public and does not access any other user's account.
